# 外贸社媒获客导师 · AI 分身提示词

> A system prompt (pure Markdown, no code) that turns any general-purpose LLM into a growth mentor for **China sourcing agents** — covering platform selection, organic content strategy, Google Search Ads, inquiry funnels, and a 90-day execution roadmap.

**一句话：** 把一个通用大模型，变成懂 Sourcing Agent 行业、懂海外社媒获客、能直接产出英文物料的顾问分身——不是聊天的角色扮演，而是带工作流、带验收标准、带商业红线的执行系统。

---

## 为什么做这个

外贸采购代理（Sourcing Agent）是一个"低频、高客单、强信任"的 B2B 生意。它的获客难点不在"不会发帖"，而在三件事同时成立：

1. 不知道**该在哪个平台**投入有限的时间，发了三个月没询盘就放弃；
2. 广告预算只有每月一千美元级别，**试错一次就伤筋动骨**；
3. 买家决策靠"人信任人"，而新公司**没有任何案例和证言**可用。

市面上的"人设提示词"大多只解决了"语气像专家"，没解决"下一步做什么、做对了怎么判断"。这份提示词试图补上后半段。

---

## 它和普通"人设提示词"的区别

| 普通做法 | 这份提示词的做法 |
|---|---|
| 堆 17 个模块，每个模块写几句漂亮话 | 模块服务于 **5 条工作流**（晨间规划 / 问题诊断 / 内容生产 / 复盘优化 / 专项交付），模块是被调用的弹药，不是摆设 |
| 规则无条件强制执行 | 规则带 **触发条件**：0 数据阶段不套用"10 倍杠杆"框架，只输出"本周唯一动作"；无落地页不允许开广告 |
| 让 AI"凭经验给建议" | **防编造设计**：明确声明不掌握任何精确行业基准；话术里的 `X%` 一律是占位符，必须用实测数据替换 |
| 只谈增长，不谈边界 | **商业红线内置**：付款条款、不垫资、出口资质、广告合规、行业违禁词全部写死在规则层 |

## 内容结构

| 模块 | 作用 |
|---|---|
| 角色 / 背景 / 任务 | 双重身份（战略导师 + 执行分身），业务背景与客户画像固化，新会话免自我介绍 |
| 写作原则（10 条） | 先诊断后开方、一次只推进一步、所有建议带验收标准、真实第一 |
| 规则与限制（15 条） | 内容合规、专业红线、付款与资质硬约束、交互规则 |
| 案例展示（2 个） | 演示"诊断 → 产出 → 避坑 → 下一步"的完整应答节奏 |
| 参考短语钩子 | 英文破冰 / 跟进 / 信任重建话术，含"无真实数据版"与"有真实数据才用版" |
| 产品与行业信息 | 服务价值主张、定价模式、6 类买家信任障碍及对应内容解法 |
| 风格与语气 / 受众 / 核心词 / 违禁词 | 输出一致性的约束层 |
| 热点信息 | 信息时效规则：不基于道听途说改策略，只基于自己的实测数据 |
| 专项一 · 平台性价比评估 | 6 维打分，输出必须含"不做清单" |
| 专项二 · 免费获客打法 | 人设定位、25 个选题方向、发布节奏、私信触达纪律、评论引流 |
| 专项三 · 谷歌搜索广告 | 四类关键词簇、否定词清单、广告组结构、5 条文案方向、1000 美元放量纪律 |
| 专项四 · 转化漏斗 | 触达 → 互动 → 私信 → 需求确认 → 报价 → 成交，逐环卡点 |
| 专项五 · 90 天路线图 | 四阶段按周拆解，含 KPI 与复盘要点 |
| AI 替代清单 | 三级分工：AI 直接做 / AI 辅助 / 不可外包 |
| 信任资产库 | 7 类信任动作 + "零订单阶段"专用规则 |
| 十倍机会扫描器 | 带触发条件的杠杆点识别，禁止把"加投放、让利抢单"当杠杆 |
| 工作流程 / 输出格式 / 初始化 | 五条工作流、四种固定输出模板、增量更新机制 |

## 快速开始

1. 打开任意支持长上下文的大模型（Claude / GPT / Gemini / 本地模型均可）；
2. 把 `SKILL.md` 中 **frontmatter 之后的全部内容**作为 System Prompt 或首条消息粘贴；
3. 第一句话直接说你的处境，例如：
   - `我刚开始做采购代理，没有任何账号和订单，先做什么？`
   - `我发了三周 LinkedIn，没人私信，是不是平台不对？`
   - `1000 美元预算投谷歌广告，怎么分词？`

若你的环境支持 Skill 目录（如 WorkBuddy / Claude Skills），直接把本文件夹放进技能目录即可自动加载。

## 复用时需要替换的 5 处

这份提示词里的业务参数是作者的真实示例。**换成你自己的事实**即可复用，替换点集中在这几处：

| 位置 | 要替换的内容 |
|---|---|
| `## 背景` → 资源与约束现状 | 所在地、团队规模、语言能力、可投入时间、预算档位、通道现状 |
| `## 产品和行业信息` → 定价模式 | 你的收费方式（打包价 / 佣金 / 混合），以及对应的内容红线 |
| `## 规则与限制` → 付款与资质红线 | 你的账期、是否垫资、是否有进出口权 |
| `## 初始化` | 你自己的信息清单与更新触发条件 |
| `## 专项二` → 品类策略 | 你的供应链优势品类，或所在产业带的素材优势 |

> **公开发布前建议：** 涉及商业条款的段落（定价、账期、垫资、资质、预算）属于经营信息。若仓库面向公众展示，建议把具体数字替换为 `【你的定价方式】` 这类占位符——模板化后复用价值更高，也不泄露谈判底牌。

## 三个设计取舍（也是它值得公开的原因）

**1. 只推荐 2–3 个平台，而不是"全平台都做"。**
一人公司的时间是硬约束。多注册一个平台，就多一份维护成本和一份"断更"的负罪感。所以专项一的输出被强制要求包含"不做清单"——**砍掉什么和选择什么同样重要**。

**2. 付费优先谷歌搜索，而不是社媒广告。**
搜索广告承接的是"已经在找采购代理"的意图，社媒广告做的是"打断式触达"。在每月一千美元的预算下，前者的每一次点击都更接近对话。社媒在这个阶段的任务是**免费建立信任**，不是买流量。

**3. 零订单阶段单独一套规则。**
没有案例、没有证言、没有账号权重时，信任只能靠"过程透明"（现场实拍、自曝式复盘、可验证信息）而不是"客户说好"。这与有案例之后的打法完全不同，混用会导致内容失真。
